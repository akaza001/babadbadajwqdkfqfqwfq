# Magnet biome exploration 0.5.0

Portable native Luau UI and authoritative integration. Combine this bundle with magnet-biome-worlds-v050 and magnet-biome-finds-v050: merge shared/server/client folders into ReplicatedStorage.MagnetWorkshop.Shared, ServerScriptService.MagnetWorkshop and StarterPlayer.StarterPlayerScripts.MagnetWorkshop. The full installer remains in the original project. Existing ui-kit was evaluated earlier; this extends the approved native WindowTheme/HudNavigation rather than inserting unrelated kit objects.

Main requires the original twelve remote events under ReplicatedStorage.MagnetWorkshop.Remotes, existing MagnetWorld and server session protocol. Preserve nonce/action sequence/activity IDs and authoritative reward validation. Bootstrap uses Studio sandbox; never copy QA profiles to production. ProfileStore contains optional backwards-compatible visitedBiomes/biomeCatches/find.biomeId. GameService and PortalService provide catches, exhibitions, travel and origin validation; no reward is granted by GuideRules.

OnboardingUI.create(host,callbacks) exposes update(view,visible,available), mark(part,position,copy) and clearMarker(). GuideRules.describe(profile,context) is read-only. context includes biomeId/equipped/onPier/away/atHome/atBench. Goal views include nine biome rows with visited/caught and targetBiomeId; FishMarker chooses nearest pier in Main. First new catch and next unvisited biome, loading/cancel/death states use prior controller protocol. All portals temporarily Open by explicit project request; equipment still determines catch tier. No E prompt.

WorkshopWindows includes inventory/collection origin labels and front-facing previews for F-13+. New modules use the approved cream/teal/gold theme and native text, not baked raster windows. Reuse existing HudIcons IDs; original PNGs are in magnet-hud-icons-v01. UI/used items are exempt from world normal. CleaningPresentation preserves ItemTransparency through fades.
