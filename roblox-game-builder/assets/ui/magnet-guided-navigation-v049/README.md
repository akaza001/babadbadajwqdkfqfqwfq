# Guided navigation UI0.4.9

Derived from approved Magnet Workshop ivory/tan/teal windows and onboarding0.4.7. No new raster image, item model, price or 3D geometry. GUI remains exempt from world normal-map policy. Existing approved models and icon assets are reused by supplied dependencies.

Entry client/OnboardingUI.luau: create(fullscreenContentFrame,{go,more})->root/update(view,visible,available)/mark(targetInstance,worldPosition,copy)/clearMarker(). Expects a safe-inset full-screen content frame at local origin under ScreenGui. Uses Camera.WorldToScreenPoint, not WorldToViewportPoint, to account for the core GUI inset. Native projected marker204x56 (narrow176x56), arrow and short copy, no input capture. Projection clamps to the central corridor between originating HUD side groups; adapt markerBounds and HUD measurements together when porting. Target removal, action/key changes, hidden UI,18second expiry and root destruction clear the mark and RenderStepped connection. Token fences preserve a replacement mark from an older delayed callback. project(size,screenPoint) is pure layout math and exposed for geometric verification.

client/PortalWalkthrough.luau: start(content,request,available)->controller{root,stop,stopped}. Requires the originating Shared.BiomeCatalog and Remotes.ActionResult, known portal marker CFrames and authoritative EnterPortal handler. Displays destination + indeterminate motion while waiting, closes on final server result/respawn. start is idempotent for a content frame, stop is idempotent and gui.Destroying disconnects handlers. Entering during cooldown/menu blocking defers request until available; a server-denied request still requires leaving/reentering. Do not change it into repeated server requests while the player stays inside after rejection.

Main.project-adapter is project-specific, not a standalone complete game. All originating client/shared dependencies are supplied; server ProfileStore/PortalService/GameService from biome-fishing-v048 or equivalent protocol is required. Marketplace textures/meshes and uploaded image ownership/availability may require checking in another universe. No real profiles/QA drivers are bundled in runtime folders.
