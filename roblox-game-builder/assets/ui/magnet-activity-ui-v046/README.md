# Fishing, cleaning and result UI0.4.6

Derived from the user-approved ivory/tan/teal window kit0.4.5. Native text/controls and actual item models; no flattened screenshot skin or new raster imports. Start from client/ActivityUI.luau and client/CastMeter.luau. World materials/normal policy are unchanged; used item geometry retains its Item exception.

ActivityUI.fishing(parent,onCancel,onTap) returns root,update(serverView),animate(tension,progress). Server stages own progress; client smoothing never grants rewards. Safe/danger feedback includes text, not color alone. Pull control uses mouse/touch InputBegan; the host retains Space/tap debounce and the authoritative remotes. Landscape panel docks bottom-left, action bottom-right; portrait stacks them. Minimum button44px; short-screen compact header. ActivityUI.cleaning(parent,onCancel) returns root,update(cleaningView,pending): both sides, readiness/flip/save status and native progress tracks.

ActivityUI.result(parent,itemDefinition,cleaned,newDiscovery,onOpen,onDismiss) returns one compact nonmodal card. Definition uses id/name/weightKg/sellCoins. The host calls it only for a committed catch or observed Dirty->Clean profile transition. Dirty price is explicitly after cleaning; no coins are awarded by UI. Main adapter replaces/dismisses one result, auto-dismisses after5seconds, clears it for new activities/menus and opens the exact UID in inventory. Explicit UID selection resets incompatible inventory filters. ActivityUI.failure(parent) is a3second nonblocking failure status via the host.

CastMeter.show(parent,{id,started},onRelease,onCancel),confirm/resume/stop. Timing/power/distance comes from Shared.CastRules/server clock. Responsive native layout preserves44px+ controls rather than scaling the entire phone UI. Existing throw/retrieve animations are reused in FishingPresentation.

CleaningPresentation retains server-validated physical brushing, two surface masks, automatic flip and camera return. New framing fits the entire flip envelope between the UI header/footer;48 item/viewport combinations x9 flip poses=432 geometric cases checked. It hides only the current workshop RoofAssembly locally while cleaning and restores previous values on stop/cancel/respawn; other players and Edit geometry are unchanged. Do not remove the restore path when adapting.

Dependencies: client modules and readonly shared sources are supplied. Main.project-adapter is the originating game's LocalScript adapter and requires its remotes/server profile protocol; this pack is not a universal standalone game. Shared procedural model sources/asset IDs may need ownership/availability checks in a different universe. Existing WindowTheme/HudIcons/WorkshopWindows are reused. No profile fixtures or QA scripts are included in the runtime folders.

Verification: real Studio viewport768x437, cast/release, mouse+Space pull, real catch F-01, actual brush movements on both sides -> Clean and new collection card, failure -> no reward, item-card inventory link, cancel/respawn -> Custom camera/model removed/roof restored/1HUD.
