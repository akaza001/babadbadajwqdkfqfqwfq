Шесть растровых макетов окон в едином стиле: инвентарь, коллекция, магазин, улучшения, продажа, настройки. Созданы встроенным image_gen по сохранённым иконкам и игровому кадру, запросы/версии в manifest.json. Это дизайн-референсы, ожидают оценки пользователя; игрового Luau и работающих окон здесь нет. Предметы и мастерская нарисованы как иллюстративные превью, это не утверждение о замене 3D-моделей в игре. Размеры/стоимости взяты из текущего balance;240монет и состояние коллекции — демонстрационные. Коллекцияr02 исправляет дубли закрытых силуэтов, r01 хранится в archive. Небольшие различия фоновых ракурсов допустимы; перед внедрением нужны адаптивные компоненты, проверка длинного текста и ввода на устройствах. Существующие edgeHUD/карта/окна не менялись.
