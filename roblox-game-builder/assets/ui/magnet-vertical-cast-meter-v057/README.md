# Vertical magnet cast meter 0.5.7

Editable native Luau component derived from magnet-activity-ui-v046, using the existing ivory/tan/teal WindowTheme. No new bitmap or model needed. Entry client/CastMeter.luau. Install into an existing MagnetWorkshop hierarchy, not as a standalone game or binary model. All real component/theme/rules/layout sources are included; no player data or admin permissions.

CastMeter.show(parent,{id,started},onRelease,onCancel) uses server-clock started, calls onRelease(activityId,elapsed) once and freezes/disabled button until server response; resume() re-enables after rejection, stop() destroys UI and disconnects Heartbeat/resize. Host supplies the same existing keyboard/gamepad/touch handlers and server validation. Repeat show calls stop; parent must supply valid AbsoluteSize. Native button and close target are >=44px. Normal panel320x330, height shrinks to parentY-24 and width to parentX-24. Verified containers869x437,390x844,568x320,320x568; smaller heights/physical devices not accepted.

Shared CastRules.position: linear rising phase elapsed modulo sweepSeconds; powerAt clamps position0..1, top means strongest. Server and client must deploy the same rules/config together; do not change just the visual marker. Upper strongMin..strongMax zone is configurable; shown example76..100%. Example Config contains originating project balance14..36studs/.8seconds only; merge the relevant settings into the host Config rather than replacing inventory/economy schema. Keep real GameService release-time validation and server-owned target; this bundle does not authorize client targets or grant rewards.

CastRules.target/retrieveTo remain project-dependent circular-lake/pier helpers with StarterLayout and FishArea attributes. Included bridge avoidance respects configured maxDistance while keeping lateral clearance10studs; adapt lake geometry before using another world. pullDuration uses host toolLevels/pull settings. WindowTheme requires included HudIcons (existing asset IDs, not generated PNG exports); this meter itself does not display icons.

Actual preview from originating Studio, no concept mockup.
