# Загрузочные экраны r01

Девять самостоятельных PNG для BIO-01…08 и BIO-10. Созданы встроенным image_gen по запросу пользователя14 ноября2026. Точные промпты, названия, пути и SHA-256: manifest.json. Это иллюстрированные макеты для просмотра, не игровые скриншоты. Новые изображения пока не импортированы в Roblox и не заменяют текущий PortalWalkthrough.

Тема: светлый блочный мир, кремовая плашка, тёмно-бирюзовые подписи и бирюзовая полоска без процентов. Плашки и текст запечены в PNG; нарисованная полоска статична. У лесного варианта название обрамлено кавычками. Перед рабочим внедрением можно отделить иллюстрацию от нативного текста/индикатора, чтобы анимация отражала состояние перехода, а подписи адаптировались к экрану.

StaticPreview.luau — переносимый адаптер просмотра: create(host, imageIds), show(id), hide(), destroy(). Ожидает реальные импортированные Roblox image IDs, не локальные пути; использует Fit для сохранения всех надписей. Он не подключён к игре. Текстуры GUI не получают мировую normal map. Файлы оригинальных генераций сохранены в проекте без изменения.
