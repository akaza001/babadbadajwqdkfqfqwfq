# Free water casting and minimal strip 0.5.8

Editable Luau sources derived from magnet-vertical-cast-meter-v057 and the existing activity UI. Entry client/CastMeter.luau; targeting shared/WaterCastRules.luau. The ivory/tan/teal WindowTheme is reused, without a visible window, labels or separate button. Actual originating-game preview included. This package requires an existing game hierarchy/services; it is not a standalone place/model.

CastMeter.show(parent,{id,started},onRelease,onCancel) draws only a translucent18px track at60%width/50%height in an invisible44px hit area; parent supplies actual safe-area size. Linear rising cycle uses server-clock started and shared CastRules. Click/tap on the hit area calls confirm; host also routes normal click/tap/Space/E. confirm freezes until the server result; resume after rejection; stop destroys the meter and disconnects Heartbeat/resize. Host handles Escape/ButtonB cancellation.5container sizes were measured, physical devices were not.

WaterCastRules.lake(world,biomeId) resolves the authored cylinder. solve(origin,look,lake,biomeId) returns same-ray candidate intervals or an error. resolve(character,world,biomeId) additionally checks live humanoid and physically reachable water. target(view,power,world) returns water target and first clear retrieval point on the same ray; stillValid checks character identity/position/facing/retained lake. The server must derive biome and root from its session and validate accepted release time; never accept a client target/direction/power. Retain nonce/sequence/rate/inventory/commit fences from the host service.

Lake contract: CircularRadius,optional InnerRadius,FishOuterRadius,WaterSurfaceY; water is non-colliding. The world filter uses RespectCanCollide to reject solid decks/rocks above water. Geometry excludes this project's central island,3StarterLayout bridge angles and2piers per distant lake. These authored geometry conventions require adaptation to another map. Solid shore segments overlapping the water cylinder are handled by bounded1stud fallback sampling on the same ray. No forced rotation; lockCharacter target=nil during aiming/casting; cleaning keeps its previous orientation behavior. Target orientation and biome come from the authoritative character/session. CastRules includes legacy pier helper functions for compatibility, but the new host path uses WaterCastRules for every target.

example/Config.luau contains only relevant originating balance4..36studs/near18/.8s and pull-duration fields. Merge these into the existing Config; do not replace a full profile/economy schema. integration/ files are exact project host adapters with unrelated host code/dependencies, not reusable replacements for arbitrary games. Current admin commands need no new profile field and keep the existing catalogs. No profiles, purchases or permission allowlists are transferred.
