# Архитектура игры

## Назначение

Размещение модулей, серверное состояние, клиентские представления.

## Сохранённое знание

Разделить общие каталоги, серверные сервисы и клиентское представление. Сохранённые Main.project-adapter предназначены для исходной игры, их нельзя считать универсальными установщиками.

## Зависимости

До реализации: [[roblox-game-builder/knowledge/topics/brief|Цель и критерии игры]]

Связанный контекст: Связи с другими темами определяются задачей.

## Ошибки и ограничения

Специального случая в реестре пока нет. Проверять границы подсистемы и интеграцию; отсутствие записи не доказывает отсутствие ошибок.

## Как проверить

Проверить владение состоянием и зависимости модулей.

## Статус готовности

- Знание/критерии: сохранены.
- Исходники: есть перечисленные пакеты; часть зависит от исходной игры.
- Проверено: только конкретные исторические случаи из отчётов пакетов; новые проверки в игре здесь не проводились.
- Запланировано: закрыть переносимость и недостающие проверки по [[roblox-game-builder/knowledge/gaps|карте пробелов]]. Не считать эту заметку готовой реализацией.
