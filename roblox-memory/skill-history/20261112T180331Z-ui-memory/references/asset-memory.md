# Постоянная память ассетов

Прямое общее указание пользователя от 12 ноября 2026. Библиотека внутри установленного скилла доступна во всех чатах, где он применяется. Она пополняется во время работы скилла, а не фоновым наблюдением за Studio. Корень путей — каталог скилла; не Downloads и не cwd игры.

## До создания

1. Определи назначение объекта и необходимые ресурсы: модель/предмет, текстуры, UI, анимации. Прочитай [единый каталог](../assets/catalog.json); ищи по kind, назначению, тегам и синонимам на русском/английском. Проверь подходящие записи и реальные исходники, а не только совпадение названия. Для объектов внутри наборов используй [библиотеку моделей](model-library.md): если состав ещё неизвестен, осмотри набор и дополни индекс доступными объектами, не считай отсутствие отдельной записи доказательством отсутствия объекта в наборе.
2. Используй подходящий сохранённый ресурс, адаптируя рабочую копию. Проверяй визуальный стиль, масштаб/UV, назначение карты, rig и совместимость. Не используй случайную текстуру только потому, что совпало слово. Если вариант не подходит, зафиксируй краткую причину и создай новый вариант. Текущее явное требование пользователя имеет приоритет.
3. Сохраняй новые ресурсы до завершения этапа. Указывай в результате, что переиспользовано и что добавлено. Не заявляй о сохранении, если сохранил только описание, скриншот или недоступную ссылку.

## Что сохранять

- Текстуры: реальный файл в `assets/textures/<stable-id>/`, назначение (color/normal/roughness и т. п.), разрешение, бесшовность и параметры масштаба/UV. Копируй результат генерации из временного расположения в скилл сразу после получения. Для пакета карт сохрани все используемые карты. Не перегенерируй подходящий готовый вариант без причины.
- Анимации: переносимый редактируемый исходник в `assets/animations/<stable-id>/` — экспортированная последовательность/клипы либо точный процедурный Luau-модуль с параметрами. Сохрани rig (R6/R15/custom), имена костей/суставов, длительность, looping, priority, переходы и зависимости. Roblox animation ID записывай дополнительно вместе с владельцем/областью доступности, если это известно. ID чужого проекта не гарантирует воспроизведение в новой игре. Если экспорт недоступен, запиши ID/рецепт как неполную запись, явно обозначь отсутствие переносимого исходника; не называй её готовым сохранённым клипом.
- Предметы: реальная модель и необходимые модули/настройки в `assets/items/<stable-id>/`, включая хват/attachments, rig, размеры, зависимости и контракт взаимодействия. Для процедурного предмета допустим воспроизводимый генератор Luau с исходными ассетами. Не сохраняй только временный экземпляр сцены или одно название. Баланс конкретной игры указывай отдельно от повторно используемого шаблона; не переносись профили/инвентари игроков.
- Другие модели/наборы: `assets/models/`; UI kit и offline money уже сохранены как исходные RBXM, их состав и работоспособность ещё не проверены. Используй только относящиеся к задаче компоненты.

## Каталог и версии

После сохранения файла обнови `assets/catalog.json`: уникальный стабильный `id`, `kind` (texture/animation/item/model), путь `file` относительно assets, теги и описание назначения, источник/дата и проект при наличии, SHA-256 и размер, статус проверки, совместимость и зависимости, Roblox asset ID или null. Для многофайлового ассета добавь `files` с путями/контрольными суммами и укажи точку входа в `file`. Не выдумывай ID. Исходные наборы дополнительно зарегистрированы в `assets/models/catalog.json`; согласуй обе записи при их изменении.

Перед записью перечитай актуальный каталог и объединяй изменения по id, сохраняя чужие записи. Совпадающий SHA-256 означает возможный дубликат: дополни теги/происхождение существующей записи вместо новой копии. Не меняй оригиналы пользователя; производные сохраняй отдельно с `derived_from`, версией и причиной. Исправляя повторно используемый шаблон, сохрани рабочую версию и обнови каталог; проектные параметры не делай общими по умолчанию. Не создавай пустые записи как будто ассет уже существует.

## Применение и проверка

Следуй [материальной политике](material-policy.md): повторное использование не отменяет обязательный рельеф объектов мира и исключение для используемых предметов. Новая декоративная текстура сама по себе не заменяет обязательную normal map. Для UI учитывай [качество интерфейса](ui-quality.md).

В проект импортируй копии, связывай зависимости и проверяй реальный результат. Локальный файл не равен загруженному Roblox asset ID. Сохранять в скилл разрешено этим указанием; публикация ассетов, дополнительные права и управление ноутбуком им не разрешаются. Различай «файл сохранён», «импортирован», «проверен в игре». При невозможности сохранить/экспортировать ресурс сообщи конкретный пробел и не обещай автоматическое повторное использование. Для другой установки переносится весь скилл вместе с assets и каталогом.
